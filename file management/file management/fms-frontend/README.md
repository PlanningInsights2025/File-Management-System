# File Management System (FMS)

## Overview
The File Management System (FMS) is a modern, responsive web application designed to streamline the management, tracking, and movement of physical and digital files within an organization. Built with React and Vite, FMS offers a professional user experience across desktop, tablet, and mobile devices.

## Features
- **Dashboard:** Overview of system activity and statistics
- **File Records:** Create, view, edit, and manage file records
- **Barcode Management:** Generate and scan barcodes for files
- **Movement History:** Track file movements and audit trails
- **Reports & Analytics:** Generate and view reports on file activity
- **User & Company Management:** Manage users, companies, racks, and permissions
- **Notification System:** Interactive notifications for system events
- **Responsive Design:** Optimized for all screen sizes
- **Sidebar Navigation:** Dynamic, route-based highlighting for easy navigation

## Technologies Used
- React (v18+)
- Vite
- React Router v6+
- Context API
- Material UI Icons
- Custom CSS (Flexbox, Grid, Media Queries)

## Getting Started
1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Run the development server:**
   ```bash
   npm run dev
   ```
3. **Open in browser:**
   Visit `http://localhost:5173` (or the port shown in your terminal)

## Usage
- Use the sidebar to navigate between modules (Dashboard, Create File, File List, etc.)
- Create, edit, and manage files and their movements
- Scan barcodes to quickly locate or update file status
- View notifications and audit trails for all file activities
